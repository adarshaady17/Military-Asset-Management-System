# Frontend

## Technologies

- React 19
- Vite 8
- Tailwind CSS 4
- React Router
- Axios
- Recharts and Lucide React

## Setup

1. Start the backend first. See [Backend setup](../Backend/README.md).
2. Create `Frontend/.env` with the backend API URL:

   ```env
   VITE_API_URL=http://localhost:5000/api
   ```

3. Install dependencies and start the development server:

   ```sh
   cd Frontend
   npm install
   npm run dev
   ```

   Open the local URL printed by Vite, usually `http://localhost:5173`.
